# Agent Space

### Overview
This application was created to help real estate agents stay organized, manage their time, and provide a better customer experience for their clients. 

#### Features
- Basic CRM
- Task management
- Mapping tools with route calculations
- Dynamic relationships

### Technology Stack
- Typescript
- Nextjs
- Tailwind
- OpenStreetMap
- Mapbox for autocomplete
- Turbo for monorepo management
- Husky for automated tooling
- Stripe for subscriptions
- NextAuth for authentication
